## Key Changes

### 1. CLI Implementation (`75e1a95`)
- Implemented `magaldi parse` command in `src/magaldi/cli.py`
- Wired together all 6 phases: Discovery → Change Detection → Parsing → Storage → Summarization → Embedding
- Added `--skip-ai` flag to skip phases 5-6
- Added `--dry-run` flag for in-memory testing without Docker

### 2. Dependency Consolidation (`c1d0e5f`)
- Removed separate `requirements.txt`, `requirements-dev.txt`, `requirements-worker.txt`
- Consolidated all dependencies into `pyproject.toml`
- Fixed ARM support by changing from `percona:8.0` to `mysql:8.0` Docker image

### 3. Real Persistence Layer (`86f01d4`)
- Created `src/magaldi/db/mysql.py` with MySQL repositories
- Created `src/magaldi/db/elasticsearch.py` with ES repository
- Added integration tests: `tests/test_db_mysql.py` (16 tests), `tests/test_db_elasticsearch.py` (14 tests)
- Pinned Elasticsearch client to `>=8.11.0,<9.0.0` for compatibility

### 4. Kibana Integration (`0d7b0b4`)
- Added Kibana 8.11.0 to `docker-compose.yml` as core service
- Available at http://localhost:5601

### 5. Environment Configuration (`e0d58eb`)
- Added `python-dotenv` for automatic `.env` file loading
- Configuration now auto-loads from `.env` without manual export
- Added `MAGALDI_SKIP_DOTENV` for test isolation
- Created `magaldi.yaml` with required scope field

### 6. Architecture Refactor (`870518e`)
Major simplification removing MySQL entirely:

**Before:**
- MySQL: file_states, code_elements, summarization_jobs, embedding_jobs
- Elasticsearch: search index only
- Redis: cache

**After:**
- Elasticsearch: code_elements (with `file_hash` for change detection), embeddings, search
- Redis: job queues (summarization, embedding)
- MySQL: **removed**

Key implementation details:
- Added `file_hash` field to ES index mapping for change detection
- Created `ElasticsearchFileStateRepository` for change detection
- Created `src/magaldi/db/redis.py` with `RedisSummarizationJobRepository`, `RedisEmbeddingJobRepository`, `RedisSummaryStore`
- Updated CLI to use ES + Redis instead of MySQL
- Updated storage module to pass `file_hash` when indexing file elements
- Removed MySQL validation from config

## Usage

```bash
# Start services
docker compose up -d

# Parse a repository
.venv/bin/magaldi parse /path/to/repo --user main

# With AI processing (requires Ollama models)
ollama pull qwen2.5-coder:7b
ollama pull snowflake-arctic-embed2
.venv/bin/magaldi parse /path/to/repo --user main

# Dry run (no Docker required)
.venv/bin/magaldi parse /path/to/repo --user main --dry-run
```
